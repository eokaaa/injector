🔧 DLL Injector

Небольшая и простая программа для инъекции DLL в выбранный процесс .exe. Поддерживает ручной выбор .dll и .exe файлов с интуитивным интерфейсом на базе ImGui.


🚀 Возможности

Выбор .dll файла для инжекции

Выбор исполняемого файла .exe процесса

Одноразовая DLL-инъекция с помощью LoadLibrary

Минималистичный и понятный GUI

📁 Как использовать

Запусти программу Injector.exe.

Нажми "Выбрать dll" и укажи путь к своей DLL.

Нажми "Выбрать exe" и выбери нужный процесс (исполняемый файл).

Нажми "Инъекция DLL в EXE" — и DLL будет загружена в процесс.

⚠️ Важно

Используется метод LoadLibrary, поэтому убедись, что путь к DLL корректен.

Некоторые антивирусы могут определять инжектор как потенциально опасное ПО (false positive).

🛠️ Сборка

Проект написан на C++ с использованием ImGui.
